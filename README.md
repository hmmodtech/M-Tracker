# M-TRACKER · ACF Gaza — نظام رصد الأخبار

سيرفر Flask بيرصد قنوات تيليجرام والمواقع الإخبارية، بيخزّن الأخبار بقاعدة بيانات،
وبيعرضها على لوحة ويب (عربي/إنجليزي) — بالإضافة إلى **تطبيق أندرويد** بيبعت إشعارات
فورية ويولّع الشاشة ويظهر الخبر لما يكون الجهاز مقفول.

```
.
├── app.py                خادم Flask + الـAPIs + الجدولة كل 30 ثانية
├── database.py           SQLite: قنوات، رسائل، مفضلات، كلمات مفتاحية،
│                         كشف تكرار الأخبار، توكنات الأجهزة
├── scraper.py            سحب t.me/s/<قناة> + المواقع
├── geocoder.py           تحويل أسماء الأماكن لإحداثيات (قاعدة غزة)
├── push.py               إشعارات Firebase (اختياري)
├── gunicorn.conf.py      إعداد التشغيل (خيوط متعددة — ضروري للبث المباشر)
├── static/               لوحة الويب + صفحة تحميل التطبيق + ملف الـAPK
└── android/              تطبيق الأندرويد (Java، بدون مكتبات خارجية)
```

## التشغيل محلياً

```bash
pip install -r requirements.txt
python app.py            # http://localhost:5000
```

## التشغيل على Render

`Procfile` و`render.yaml` جاهزين:

```
web: gunicorn app:app -c gunicorn.conf.py
```

متغيّرات بيئة اختيارية:

| المتغيّر | الوظيفة |
|---|---|
| `PORT` | منفذ التشغيل (Render بيحدده) |
| `DB_PATH` | مكان قاعدة البيانات (افتراضي `ttracker.db`) |
| `SECRET_KEY` | مفتاح جلسات Flask (الأفضل تثبيته) |
| `STREAM_TOKEN` | مفتاح سري لـ`/api/stream` (إذا فعّلته لازم تكتبه بالتطبيق) |
| `FIREBASE_CREDENTIALS_PATH` | ملف خدمة Firebase إذا بدك إشعارات FCM |

## واجهات API

| المسار | الوظيفة |
|---|---|
| `GET /api/messages` | الأخبار (بحث/قناة/حرجة) |
| `GET /api/stream` | **البث المباشر** (long-poll) — يستخدمه تطبيق الأندرويد |
| `POST /api/scrape` | سحب الأخبار الآن |
| `GET /api/stats` | إحصائيات |
| `GET /api/channels` · `GET /api/keywords` · `GET /api/bookmarks` | القنوات/الكلمات/المفضلات |
| `POST /api/login` · `GET /api/me` · `POST /api/logout` | الدخول |
| `GET /app` | صفحة تحميل تطبيق الأندرويد |

### كيف يشتغل `/api/stream`

```
GET /api/stream?baseline=1                 ← التطبيق يسجّل نقطة البداية (ما بيعيد القديم)
GET /api/stream?since=1234&wait=25&scope=critical
        ← السيرفر بيمسك الطلب لحتى يوصل خبر جديد (أو 25 ثانية)
        → {"events":[...], "cursor":1235}
```

- `cursor` بيتقدم دايماً — حتى الأخبار المفلترة (المكرّرة) ما بترجع مرة ثانية.
- الأخبار المتشابهة (نفس الحدث من عدة قنوات) بتتدمج بإشعار واحد.
- `scope=all` لكل الأخبار، `scope=critical` للأخبار المهمة فقط، `dedup=0` لإيقاف الدمج.
